# 📰 BlogXer - News & Blog Website

A modern, responsive blog and news portal website built with **HTML5, CSS3, Bootstrap 5**, and a touch of **JavaScript**. BlogXer is designed to deliver clean layouts, featured articles, categorized news, and a smooth reading experience.

## 📝 Project Description

**BlogXer** is a frontend-only static blog template suitable for news, articles, or personal blogging platforms. It features a responsive layout, blog category sections, hero posts, and newsletter subscription – all designed for readability and engagement.

---

## 🧩 Key Features

### 🧭 Header + Navigation
- Clean navbar with logo and links (Home, About, Categories, Contact)
- Mobile responsive with collapse menu

### 🏆 Hero Section
- Featured blog posts with large thumbnail and headlines
- Subheadline and post date

### 🗂️ Category Highlights
- Grid layout using Bootstrap 5
- Categories like Business, Travel, Food, Technology, and more

### 📰 Recent Blog Posts
- Blog cards with image, title, and brief content
- “Read More” button for extended blog post navigation

### 📧 Newsletter Signup
- Stylish email subscription box with CTA

### 📞 Footer Section
- About info
- Quick links
- Contact information and social media icons
